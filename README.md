# Micronutrient Deficiency Mapping

## 📌 Project Overview
This project focuses on the geographical and demographic mapping of micronutrient deficiencies, specifically targeting Iron and Vitamin D levels. It serves as an epidemiological study tool within the domain of **Human Nutrition and Public Health Dietetics**.

## 🔬 Key Objectives
- Identify regional disparities (Urban vs. Rural) in essential micronutrient levels.
- Analyze the distribution of iron deficiency across different age groups and genders.
- Categorize and visualize the severity of nutritional deficiencies to aid public health interventions.

## 📂 Files Included
- `deficiency_data.csv`: A demographic dataset containing clinical values for Iron and Vitamin D.
- `map_deficiencies.py`: Python script for statistical aggregation and Seaborn-based visualizations.
- Visual outputs (`iron_distribution.png`, `deficiency_severity.png`).

## 🛠️ Tools Used
- Python 3, Pandas, Seaborn, Matplotlib

## 🚀 How to Run
```bash
pip install pandas matplotlib seaborn
python map_deficiencies.py
```

## 📊 Findings Summary
- Rural populations demonstrated significantly lower average Vitamin D and Iron levels compared to urban counterparts.
- Children and female adults showed the highest variance in iron levels, marking them as high-risk demographic groups.
